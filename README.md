## Contribution Animation

GitHub's built-in contribution graph remains available on your profile. The snake animation is optional because it requires GitHub Actions to generate an image in your profile repository.

<details>
  <summary><b>Enable the contribution snake animation</b></summary>

  **Step 1 — Create this workflow file**

  Create `.github/workflows/snake.yml` in your profile repository:

  ```yaml
  name: Generate contribution snake

  on:
    workflow_dispatch:
    schedule:
      - cron: "17 */12 * * *"
    push:
      branches:
        - main

  permissions:
    contents: write

  jobs:
    generate:
      runs-on: ubuntu-latest
      timeout-minutes: 10

      steps:
        - name: Generate snake SVGs
          uses: Platane/snk/svg-only@v3
          with:
            github_user_name: ${{ github.repository_owner }}
            outputs: |
              dist/github-snake.svg
              dist/github-snake-dark.svg?palette=github-dark

        - name: Publish generated files to output branch
          uses: crazy-max/ghaction-github-pages@v3.1.0
          with:
            target_branch: output
            build_dir: dist
          env:
            GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
  ```

  **Step 2 — Check repository settings**

  Ensure GitHub Actions is enabled and that the workflow has permission to write repository contents. Run the workflow manually from the Actions tab.

  **Step 3 — Display the generated image**

  After the `output` branch contains the SVG files, use the following snippet:

  ```html
  <picture>
    <source
      media="(prefers-color-scheme: dark)"
      srcset="https://raw.githubusercontent.com/AbderrahmanEMD/AbderrahmanEMD/output/github-snake-dark.svg">
    <source
      media="(prefers-color-scheme: light)"
      srcset="https://raw.githubusercontent.com/AbderrahmanEMD/AbderrahmanEMD/output/github-snake.svg">
    <img
      alt="Animated snake traversing my GitHub contribution graph"
      src="https://raw.githubusercontent.com/AbderrahmanEMD/AbderrahmanEMD/output/github-snake.svg"
      width="100%">
  </picture>
  ```

  The workflow creates the image; the README alone cannot create or update it.

  Project documentation: https://github.com/Platane/snk

</details>
